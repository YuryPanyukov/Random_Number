# Случайные числа 🎲

Android-приложение для генерации случайных чисел с сохранением «сессий» генерации:
задайте диапазон, включите режим «без повторений» и получайте числа, которые не
повторяются, пока весь диапазон не будет исчерпан.

## Возможности

### Генерация

- **Батч-генерация** — за одно нажатие 1/2/3/5/10 чисел; в режиме «без повторений»
  числа в батче уникальны, при частичном исчерпании выдаются оставшиеся.
- **Пресеты диапазонов** — «Кубик 1–6», «Монета 0–1», «Лотерея 1–45», «Сотня 1–100»
  создаются одним тапом.
- **Ручное редактирование истории** — добавление числа вручную (с валидацией
  диапазона и повторов), удаление отдельного числа, отмена последнего.
- **Seed (воспроизводимость)** — зафиксированный seed даёт одну и ту же
  последовательность: розыгрыш можно проверить повторным прогоном. Seed имеет
  приоритет над выбором источника случайности.
- **Источник случайности** — обычный ГПСЧ Kotlin или криптографический
  `SecureRandom` («безопасный режим» для розыгрышей).

### Сессии

- **Список сессий** — продолжить, удалить (с подтверждением), сортировка по
  времени использования.
- **Диалог «Все числа выбраны!»** — когда в режиме «без повторений» выбран весь
  диапазон: создать новую сессию или сбросить текущую.
- **Статистика сессии** — количество, уникальные, повторы, мин/макс, среднее,
  медиана, самое частое/редкое число.
- **Журнал с таймстампами** — каждое число хранится с временем выдачи
  (старые данные мигрируют автоматически).

### Экспорт и импорт

- **Экспорт истории** — CSV (с таймстампами), TXT (список), JSON (сессия целиком)
  через системный диалог сохранения; при недоступности — share-sheet.
- **Перенос всех сессий** — версионированный JSON-файл: экспорт на одном
  устройстве, импорт на другом; повреждённые файлы и несовместимые версии
  распознаются и не «съедают» данные.

### Персонализация

- **Тема** — системная/светлая/тёмная, акцентный цвет (динамический Android 12+,
  индиго, бирюза, роза).
- **Отклик при генерации** — вибрация и/или короткий звук; опционально сигнал
  на каждое число батча.
- **Локализация** — русский и английский (все строки в ресурсах).

### Ключевая логика: режим «без повторений»

`NumberGenerator.next(...)` возвращает `GenerationResult.Success(number)` либо
`GenerationResult.Exhausted`, когда все числа диапазона выбраны. Для больших
диапазонов используется комбинированная стратегия: 128 быстрых «бросков»,
затем выбор свободного значения обходом по кругу от случайного сдвига —
сложность не зависит от размера диапазона (для 1..10 000 000 это миллисекунды).

`Session` хранит журнал `log: List<GeneratedEntry(value, at)>` и вычисляет
`pickedCount` / `isExhausted`; `SessionViewModel.generate()` добавляет батч,
сохраняет сессию и показывает диалог исчерпания, если числа кончились.

### Устойчивость хранилища

- каждая сессия лежит отдельным ключом (`session_<id>`), запись одной сессии
  не переписывает остальные;
- повреждённая запись пропускается при чтении, логируется и **не затирается**
  следующей записью;
- данные старого формата (одна JSON-строка) переносятся автоматически;
- операции над состоянием сессии выполняются последовательно в одной очереди:
  быстрые повторные нажатия не теряют числа;
- удалённая сессия не «воскресает» повторным сохранением.

## Тесты

193 unit-теста (`./gradlew testDebugUnitTest`), 0 падений:

- `NumberGeneratorTest` — диапазоны, батчи, отсутствие повторов, исчерпание,
  детерминизм по seed, полная выборка диапазона;
- `RandomSourceTest` — `SecureRandom`-адаптер, широкие диапазоны, границы;
- `SessionTest` — журнал, добавление/удаление чисел, ручной ввод, валидация;
- `SessionRepositoryTest` — создание/обновление/удаление, сортировка,
  сброс чисел, устойчивость к повреждённым записям;
- `SessionCodecTest` — round-trip JSON, битые данные, миграция старого формата;
- `HistoryExporterTest` / `SessionTransferTest` — форматы экспорта,
  версионированный перенос, повреждённые файлы;
- `SessionViewModelTest` — генерация, батчи, отмена, ручной ввод, seed,
  экспорт истории, полный обход диапазона через ViewModel;
- `HomeViewModelTest` — список сессий, удаление, импорт/экспорт;
- `NewSessionViewModelTest` — валидация формы, пресеты, переживает поворот;
- `SettingsViewModelTest` — изменение настроек.
