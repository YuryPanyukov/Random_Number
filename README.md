# Случайные числа 🎲

Android-приложение для генерации случайных чисел с сохранением «сессий» генерации:
задайте диапазон, включите режим «без повторений» и получайте числа, которые не
повторяются, пока весь диапазон не будет исчерпан.

## Возможности

- **Главное меню** — список сохранённых сессий (показывается при запуске) с
  возможностью продолжить любую из них или удалить (с подтверждением).
- **Новая сессия** — параметры генерации:
  - диапазон чисел «От … До» с валидацией;
  - переключатель **«Без повторений»**: ранее сгенерированные числа не выдаются снова.
- **Экран генерации**:
  - крупное последнее число и кнопка «Сгенерировать»;
  - прогресс «Выбрано X из Y» и индикатор для режима без повторений;
  - **полная история** выданных чисел с кнопкой «Скрыть / Показать»;
  - кнопка «Сбросить числа» — продолжить текущую сессию, сбросив выбранные.
- **Диалог «Все числа выбраны!»** — когда в режиме «без повторений» выбран весь
  диапазон, приложение предлагает создать новую сессию или продолжить текущую со
  сбросом ранее выбранных чисел.
- **Персистентность** — сессии хранятся между запусками (Preferences DataStore, JSON).
- Выход из сессии всегда возвращает в главное окно.

```
│   └── SessionCodec.kt        # JSON-кодек (сериализация сессий)

│   └── NumberGenerator.kt     # генерация чисел + логика «без повторений»

    ├── AppNav.kt              # навигация: home → new_session → session

```

### Ключевая логика: режим «без повторений»

`NumberGenerator.next(min, max, allowRepeats, generated)` возвращает
`GenerationResult.Success(number)` либо `GenerationResult.Exhausted`, когда все
числа диапазона выбраны. Источник `Random` вынесен в конструктор — генератор
детерминирован в тестах. Быстрые «броски» чередуются с точным перебором остатка,
поэтому корректность не зависит от размера диапазона.

`Session` хранит `generated: List<Int>` и вычисляет `pickedCount` / `isExhausted`;
`SessionViewModel.generate()` добавляет число, сохраняет сессию и сразу показывает
диалог исчерпания, если числа кончились.

## Тесты

42 unit-теста (`./gradlew testDebugUnitTest`):

- `NumberGeneratorTest` — диапазоны, отсутствие повторов, исчерпание,
  детерминизм по seed, полный обход 0…100 (101 уникальное число, затем — `Exhausted`,
  новых чисел не генерируется);
- `SessionRepositoryTest` — сохранение, сортировка, удаление, сброс чисел;
- `SessionCodecTest` — round-trip JSON, битые данные, неизвестные поля;
- `SessionViewModelTest` — генерация, диалог исчерпания, сброс, события навигации,
  полный обход 0…100 через ViewModel;
- `HomeViewModelTest` — список сессий и удаление.

## Запуск

```bash
./gradlew testDebugUnitTest   # unit-тесты
./gradlew assembleDebug       # сборка APK
```

Или откройте проект в Android Studio и запустите на устройстве/эмуляторе.

## Планы развития

- Ограничение размера диапазона в режиме «без повторений» (защита памяти).
- Хранение только последних N чисел для очень больших диапазонов.
- Экспорт истории генерации.
