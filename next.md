### Что сделано особенно удачно (не трогать)

- `SessionStorage`: раскладка «сессия = отдельный ключ + индекс», устойчивость к битым записям (пропуск + лог, без затирания), автоперенос legacy-формата. Отличный фундамент для виджета (5.4).

- `SessionTransfer`: версионированный формат экспорта/импорта — расширяемо без поломки старых файлов.

## 4. Идеи по Этапу 2 (режимы) — детализация

### 4.1. Абстракция режимов (2.0) — ключевые решения, которые нужно принять заранее
Сейчас `Session` жёстко про числа (`min..max`, `List<Int>`). Предлагаю не переусложнять:

- **Не** делать универсальный `GenerationMode` с обобщениями на уровне хранилища. Вместо этого — sealed-тип `SessionPayload` (`Numbers` / `Dice` / `Coin` / `Items`) внутри `Session`, а `SessionCodec` пишет `type`-дискриминатор. Старые сессии читаются как `Numbers` (обратная совместимость уже проверена на миграции legacy).
- Общий контракт генерации оставить максимально узким: `interface Generator<T> { fun next(state: T): T }` — кубики и монетка не требуют «без повторений», список — требует. Не тащить `pickUnique` во все режимы.
- Экран сессии: один общий каркас (журнал, экспорт, статистика) + слот для «результата режима» (крупное число / сумма кубиков / орёл-решка). Это позволит не плодить 4 экрана.

Оценка: **L**, но это окупается на всех следующих задачах.

**Статус: выполнено 2026-10-01.** Реализовано как sealed-тип `SessionPayload` в `data/`
(`Numbers(min, max, allowRepeats)` — единственный подтип пока): `Session` хранит `payload`,
плоский конструктор и свойства сохранены — весь существующий код не тронут.
JSON — дискриминатор `type`; старые записи (корневые `min/max/allowRepeats`, плоский
`generated`) и старые экспортные файлы читаются через нормализацию `SessionCodec`.
Домен (`NumberGenerator`) не обобщался: общий контракт генерации — при добавлении
конкретных режимов 2.1–2.4, когда будет видно настоящее пересечение. Детали — в

- **Пресеты с сохранением пользовательских:** сейчас пресеты фиксированы (Кубик/Монета/Лотерея/Сотня). Дать «сохранить как пресет» из формы новой сессии (S–M).
